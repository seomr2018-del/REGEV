# REGEV — לוח לידים

ריפו זה מרכז את דשבורד ניהול הלידים ("לוח לידים") לצד האיפיון המלא שלו.

## מבנה הריפו

```
.
├── dashboard/
│   └── index.html              # הדשבורד עצמו — קובץ HTML עצמאי, ניתן לפתיחה ישירה בדפדפן
└── docs/
    └── leads-dashboard/
        ├── SPEC.md              # איפיון מוצר מלא (מטרות, מסכים, מודל נתונים, אינטראקציות)
        └── dashboard.spec.json  # Spec מכונה-קריא, תואם 1:1 למימוש בפועל בקוד
```

## איך זה מתחבר

- `dashboard/index.html` הוא עותק מלא ומעודכן של הדשבורד שפורסם כ-Artifact:
  https://claude.ai/artifact/6T5KrGmL4962AhFHAVpfhD
- `docs/leads-dashboard/SPEC.md` מתעד בעברית את כל ההתנהגות, מודל הנתונים,
  השלבים (Stages), ה-KPIs והאינטראקציות של הדשבורד — קריא לבני אדם.
- `docs/leads-dashboard/dashboard.spec.json` מתאר את אותו איפיון בפורמט
  מובנה (JSON), לשימוש בכלים אוטומטיים, בדיקות רגרסיה, או כבסיס למימוש מחדש.

כל שינוי עתידי בדשבורד צריך להתעדכן במקביל בשני קובצי ה-spec, כדי לשמור
עליהם כמקור אמת עדכני.
